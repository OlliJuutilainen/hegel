# How this file works
//
// Each non-blank, non-comment line starting with `#` is one outline entry.
// More `#`'s = deeper nesting (## under #, ### under ##, etc).
//
// Optional `@ N` after the title is a 1-based page hint, used to disambiguate
// when the heading also appears in the book's own table-of-contents pages.
// Lines starting with `//` are comments and ignored.
//
// To show a SHORT label in the outline but still match a long heading in the
// body text, put the exact body wording in brackets on the line below:
//
//   ## c. Observation (relation to immediate actuality)
//   [c. Observation of the relation of self-consciousness to its immediate actuality. Physiognomy and phrenology]
//
// The `##` line is the label shown; the `[...]` line is what gets searched.
//
// Usage:
//   python add_outline.py outline.md Between_Kant_and_Hegel_OCR.pdf out_outlined.pdf
